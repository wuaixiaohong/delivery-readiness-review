# 功能交付审查与修复技能

这是一个面向 Codex Agent Skills 的多语言交付质量技能。它根据 PRD、产品原型、验收标准和实际代码，检查并修复功能遗漏、前后端接口契约不匹配、字段错误及业务代码缺陷，再执行适当的回归验证。

适用场景：

- 后端实现交前端联调前，核对接口、字段、校验、错误返回和业务行为。
- 前端实现交测试前，核对原型交互、请求组装、页面状态及异常处理。
- 前后端整体交测试前，沿用户操作到数据持久化和页面回显检查端到端行为。

默认工作方式是“审查 → 修复 → 复验”。明确要求“只审查”“只分析”或“暂不修改”时，技能只读并报告问题。此技能不执行安全漏洞扫描。

## 安装

将本仓库作为一个 Agent Skill 放入 Codex 可发现的 skills 目录，例如个人目录：

```text
~/.agents/skills/delivery-readiness-review/
```

确保 `SKILL.md` 位于上述目录下。Codex 发现技能后，可用 `$delivery-readiness-review` 调用。

## 使用

```text
$delivery-readiness-review 根据 PRD 和原型检查订单功能，修复后端接口与前端字段不匹配的问题，并运行相关测试。
```

或限定为只读审查：

```text
$delivery-readiness-review 只审查，不要修改代码。检查该功能是否满足原型和验收标准。
```

## 文件

- `SKILL.md`：审查、修复和验证流程。
- `review-examples.md`：字段贯通、接口响应、需求冲突和交付方向示例。

## 范围边界

技能按项目实际技术栈和证据开展工作，不假定某种语言或架构。缺少需求、原型、某一端代码或运行环境时，明确说明未验证范围；不会把静态阅读、mock 或构建成功表述为完整业务验收。不会自动提交代码、部署或修改线上数据。
